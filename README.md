# پرداخت

## دریافت فهرست درگاه‌ها

پذیرنده می‌تواند با استفاده از API زیر، فهرست درگاه‌های پرداخت فعال و در دسترس خود را دریافت کند.

### Endpoint

```text
https://api.zarinplus.com/payment/gateways/
```

### متد درخواست

`POST`

### بدنه درخواست

```json
{
    "token": "9a1bfc8895cc5df72715fe81f6ac121936d00b61"
}
```

### توضیحات پارامترها

- `token`: توکن احراز هویت پذیرنده. ارسال این پارامتر الزامی است.

### نمونه پاسخ موفق

```json
{
    "status": true,
    "message": "successful",
    "data": [
        {
            "id": 1,
            "title": "زرین پلاس",
            "description": "درگاه اقساطی",
            "slug": "zarinplus",
            "icon": "https://api.zarinplus.com/media/payment/2026-04-21/ZarinPlus.png"
        },
        {
            "id": 3,
            "title": "وایب",
            "description": "پرداخت با اعتبار وایب و کارت رفاهی(بانک رفاه کارگران)",
            "slug": "vibe",
            "icon": "https://api.zarinplus.com/media/payment/2026-04-21/Vibe.png"
        }
    ]
}
```

## ایجاد درخواست پرداخت

برای آغاز فرایند پرداخت، پذیرنده باید از API ایجاد درخواست پرداخت استفاده کند. در صورت موفقیت درخواست، یک کد `authority` و آدرس `redirect_url` جهت هدایت کاربر به صفحه پرداخت دریافت خواهد شد.

### Endpoint

```text
https://api.zarinplus.com/payment/v2/request/
```

### متد درخواست

`POST`

### پارامترهای ارسالی

```json
{
    "amount": 50000,
    "cancel": "http://www.mystore.com/cancel/",
    "success": "http://www.mystore.com/success/",
    "item": "5000 Toman Voucher",
    "cellphone": "09121111111",
    "email": "yourname@domain.com",
    "token": "9a1bfc8895cc5df72715fe81f6ac121936d00b61",
    "gateway_slug": "zarinplus"
}
```

### توضیحات پارامترها

- `amount`: مبلغ تراکنش به‌صورت عدد صحیح.
- `cancel`: آدرس URL که در صورت لغو فرایند پرداخت، کاربر به آن هدایت می‌شود.
- `success`: آدرس URL که پس از انجام موفق فرایند پرداخت، کاربر به آن هدایت می‌شود.
- `item`: عنوان یا توضیحات مربوط به کالا، خدمت یا تراکنش.
- `cellphone`: شماره تلفن همراه خریدار.
- `email`: آدرس ایمیل خریدار.
- `token`: توکن احراز هویت پذیرنده. ارسال این پارامتر الزامی است.
- `gateway_slug`: مقدار `slug` یکی از درگاه‌های فعال دریافت‌شده از API فهرست درگاه‌ها.

### نمونه پاسخ موفق

در صورت ارسال صحیح اطلاعات و ایجاد موفق درخواست پرداخت، پاسخی مشابه نمونه زیر دریافت خواهد شد:

```json
{
    "status": true,
    "message": "Get the authority code",
    "authority": "f72705fe8a9bfc8895cc5dac121931f696d00b61",
    "redirect_url": "https://pwa.zarinplus.com/authority=f72705fe8a9bfc8895cc5dac121931f696d00b61&phone=09121111111"
}
```

### هدایت کاربر به صفحه پرداخت

پس از دریافت `authority`، پذیرنده باید کاربر را به آدرس موجود در فیلد `redirect_url` هدایت کند تا فرایند پرداخت تکمیل شود.

## لغو تراکنش

در صورت لغو فرایند پرداخت توسط کاربر، امکان ثبت لغو تراکنش از طریق API زیر وجود دارد.

### Endpoint

```text
https://api.zarinplus.com/payment/v2/cancel/
```

### متد درخواست

`POST`

### پارامترهای ارسالی

```json
{
    "authority": "f72715fe8a1bfc8895cc5dac121931f696d00b61"
}
```

### توضیحات پارامترها

- `authority`: کد مجوز تراکنش که هنگام ایجاد درخواست پرداخت دریافت شده است.

### نمونه پاسخ موفق

در صورت لغو موفق تراکنش، پاسخی مشابه نمونه زیر دریافت خواهد شد:

```json
{
    "status": true,
    "message": "You have canceled transaction"
}
```

## تأیید تراکنش

پس از تکمیل فرایند پرداخت توسط کاربر، پذیرنده باید تراکنش را از طریق API تأیید (`Verify`) بررسی و نهایی کند.

### Endpoint

```text
https://api.zarinplus.com/payment/v2/verify/
```

### متد درخواست

`POST`

### پارامترهای ارسالی

```json
{
    "authority": "f72715fe81f69a1bfc8895cc5dac121936d00b61",
    "token": "9a1bfc8895cc5df72715fe81f6ac121936d00b61",
    "amount": 50000
}
```

### توضیحات پارامترها

- `authority`: کد مجوز تراکنش که در مرحله ایجاد درخواست پرداخت دریافت شده است.
- `token`: توکن احراز هویت پذیرنده. ارسال این پارامتر الزامی است.
- `amount`: مبلغ تراکنش.

### نمونه پاسخ موفق

```json
{
    "status": true,
    "message": "Successful",
    "data": {
        "code": 200,
        "message": "Successful",
        "amount": 50000,
        "currency": "IRR",
        "reference": "512c773635c2a716340ce70bdddad25ace806378",
        "cellphone": "09226521257",
        "user_cellphone": "989337679420"
    }
}
```

### نکته مهم در تأیید تراکنش

در این API بررسی مقدار `response['data']['code']` الزامی است.

در اولین تأیید موفق یک `authority`، مقدار `code` برابر با `200` خواهد بود. در صورتی که همان `authority` مجدداً برای تأیید ارسال شود، مقدار `code` به `201` تغییر می‌کند.

بنابراین، در حالت استاندارد، پذیرنده باید **صرفاً در صورت دریافت کد `200`، سفارش یا فاکتور کاربر را موفق و نهایی‌شده در نظر بگیرد**.

استفاده از کد `201` به‌عنوان وضعیت موفق تنها در شرایط خاص و در صورت نیاز به پیاده‌سازی منطق اختصاصی انجام شود.

## بازگشت تراکنش

پذیرنده می‌تواند یک تراکنش موفق را از طریق API زیر بازگرداند.

### Endpoint

```text
https://api.zarinplus.com/payment/v2/reverse/
```

### متد درخواست

`POST`

### پارامترهای ارسالی

```json
{
    "reference": "46a1e78525619a25b368c32b9ba11b92f6063e0c",
    "authority": "f72715fe8a1bfc8895cc5dac121931f696d00b61",
    "token": "9a1bfc8895cc5df72715fe81f6ac121936d00b61"
}
```

### توضیحات پارامترها

- `reference`: شناسه مرجع تراکنش که پس از تأیید موفق تراکنش دریافت شده است.
- `authority`: کد مجوز مربوط به تراکنش.
- `token`: توکن احراز هویت پذیرنده. ارسال این پارامتر الزامی است.

### نمونه پاسخ موفق

در صورت بازگشت موفق تراکنش، پاسخی مشابه نمونه زیر دریافت خواهد شد:

```json
{
    "status": true,
    "message": "success",
    "data": {
        "code": 101,
        "message": "Reversed",
        "amount": 1000000,
        "currency": "IRR",
        "item": "Item description",
        "email": "example@example.com",
        "cellphone": "09226521257"
    }
}
```

## بازگشت بخشی از مبلغ تراکنش

این API برای بازگشت بخشی از مبلغ یک تراکنش مورد استفاده قرار می‌گیرد.

### Endpoint

```text
https://api.zarinplus.com/payment/refund-part-of-tx/
```

### متد درخواست

`POST`

### بدنه درخواست

```json
{
    "reference": "46a1e78525619a25b368c32b9ba11b92f6063e0c",
    "reason": "test",
    "token": "9a1bfc8895cc5df72715fe81f6ac121936d00b61",
    "refund_amount": 1500
}
```

### توضیحات پارامترها

- `reference`: شناسه مرجع تراکنش اصلی که در مرحله تأیید تراکنش دریافت شده است.
- `reason`: دلیل بازگشت بخشی از مبلغ تراکنش. ارسال این پارامتر اختیاری است.
- `token`: توکن احراز هویت پذیرنده. ارسال این پارامتر الزامی است.
- `refund_amount`: مبلغ موردنظر برای بازگشت.

### نمونه پاسخ مورد انتظار

```json
{
    "status": true,
    "message": "success",
    "data": {
        "original_transaction_id": 1,
        "original_amount": 200000,
        "actual_refund_amount": 1500,
        "replacement_transaction": {
            "authority": new_authority,
            "reference": new_reference,
            "amount": new_transaction_amount
        },
        "refunded_at": "2026-12-12 10:12:12"
    }
}
```

## فهرست کدهای وضعیت

| کد | توضیحات |
|---:|---|
| `200` | تراکنش با موفقیت تأیید شده است. |
| `201` | این تراکنش قبلاً با همین `authority` تأیید شده و درخواست تأیید مجدداً ارسال شده است. |
| `400` | کد مجوز نامعتبر است. |
| `401` | توکن ارسال‌شده نامعتبر است. |
| `403` | درخواست غیرمجاز است. |
